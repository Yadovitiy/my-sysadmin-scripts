# Мониторинг ресурсов

Скрипт раз в N секунд собирает статистику системы ('free -h', 'df -h', 'uptime') 
и дописывает её в 'monitor.log' с временной меткой.
Вывод лога - в соответсвии с заданием. без разделителей для удобства читаемости (т.к. это не было определено в задании, решил не рисковать несоответствием).
